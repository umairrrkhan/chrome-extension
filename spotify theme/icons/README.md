# Aura icon

Minimal charcoal lowercase a on soft lavender, generated for Aura.

- `icon1024.png`: high-resolution master.
- `icon512.png`: large export.
- `icon16.png`, `icon32.png`, `icon48.png`, `icon128.png`: Chrome extension exports, declared in the manifest.

All files are square PNGs. Smaller sizes use Lanczos downsampling from the same master.
